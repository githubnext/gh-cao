# Support

## How to get help

Central Agentic Ops uses [GitHub issues](https://github.com/githubnext/gh-cao/issues)
to track bugs, feature requests, and usage questions. Search existing issues
before opening a new one, and do not include credentials or sensitive data.

Central Agentic Ops is a research prototype under active development and is
maintained by GitHub Next. We will do our best to respond to support requests
and community questions, but features and interfaces may change without notice.

For security vulnerabilities, follow the private reporting instructions in
[SECURITY.md](SECURITY.md) instead of opening a public issue.

## GitHub Support policy

Support for this project is limited to the resources listed above. This project
is not covered by GitHub Support or GitHub Enterprise Support plans.
