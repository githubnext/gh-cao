# Support

Use [GitHub issues](https://github.com/githubnext/gh-cao/issues) for CAO bugs,
feature requests, usage questions, and documentation problems. Search existing
issues before opening a new one.

Include the CAO version or commit, deployment mode, expected and actual
behavior, reproduction steps, and relevant sanitized logs. Never include
credentials, tokens, private repository data, or other sensitive information.

For contribution proposals, follow [CONTRIBUTING.md](CONTRIBUTING.md). Report
suspected vulnerabilities privately through [SECURITY.md](SECURITY.md), not in
a public issue.

CAO is a GitHub Next research project under active development. Maintainers
respond on a best-effort basis, and features or interfaces may change. CAO
support is not covered by GitHub Support or GitHub Enterprise Support plans.
