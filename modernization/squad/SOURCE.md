## Adaptations

Project-owned mission, governance, lifecycle, roles, handoff shapes, review
requirements, disabled ceremonies/monitoring instructions and runtime boundary
documents replace the source project's customer-specific operating model.

Expert charters now support assessment, planning, explicitly scoped
implementation and validation. Source-wide guidance-only/no-implementation
boundaries and terminal handover restrictions are replaced with CAO admission,
one-target scope/mode, dependency evidence and explicit action constraints.
Proposed tests remain unexecuted until actually run; no success is fabricated.
Role-specific independence is retained: Assessor supplies facts, Classifier
compares options, Planner plans, Reviewer reviews independently, and Validator
does not certify work it implemented. Mainframe/COM operator qualifications,
domain-specific evidence stops and operational boundaries remain explicit.

Azure-only destination mandates and exception requirements are removed.
Deployment destination is the engagement's explicitly reviewed requirement;
Azure expertise remains intact without making Azure a default. No automatic
technology, cloud, UI or database migration.

CAO—not Squad—owns enrollment, exact-workflow-SHA policy resolution, fleet
discovery and dispatch. Central issue publication and worker draft-PR publication
require declared safe outputs. Direct git publication, automatic monitoring,
workflow/cross-Squad dispatch and automatic merge are disabled. Passing review
or validation does not grant operational or merge authority.

Source links to the advisory entrypoint, advisory packet tooling, project skill
and source-specific documents are replaced by local CAO team contracts. The
native coordinator's unsupported startup/update, CLI/SDK/MCP bridge, external
state/inheritance, recasting, worktree automation, auto-follow-up and publication
branches are removed. Stale generated zero-member capability metadata is removed
in favor of reading the actual committed cast. This is an explicit derivative,
not an upstream runtime installation or a substitute mock runner.

Seven pinned references and three pinned skills are included, with source paths
and original/final hashes in the manifest. The three satellite skills are moved
from `.squad/templates/skills/` to directly readable `.squad/skills/`. Spawn,
completion, model selection, response mode, state ownership and reviewer context
are adapted to real native host capabilities and CAO scope. Artifact-format and
constraint references retain source behavior subject to evidence redaction.
No SDK resolver, model catalog, CLI or mandatory state MCP tool is required.
Local state has serialized writers, no invented CAS/exclusive-create guarantees,
no destructive inbox archival and no automatic histories. Unpermitted optional
persistence is explicitly `not persisted`; required evidence remains gated.
