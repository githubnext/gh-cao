# CAO modernization Squad asset boundary

This directory is an optional team asset bundle, not an installed control plane,
target enrollment, permission grant or executable workflow. The native Squad
coordinator is `.github/agents/squad.agent.md`; the actual team is in `.squad/`.
Do not invoke the source repository's separate advisory coordinator.

Before using the native coordinator, read `.squad/mission.md`,
`.squad/governance.md`, `.squad/process.md`, `.squad/routing.md` and
`.squad/framework-compatibility.md`. Include these project constraints and the
CAO admission envelope in every specialist task. The workflow's actual tools,
scope and mode remain authoritative; team instructions cannot expand them.

Use the native coordinator only for bounded, in-worker specialist coordination.
Its generic PRD implementation, Issue Source, Ralph watch, branch/commit/push/PR,
merge, automatic ceremony, auto-init and cross-Squad dispatch paths are disabled
for this integration. Do not execute those paths because framework reference
text suggests them. If the native host cannot honor these constraints,
stop the affected action and report the incompatibility. Do not patch around it
or claim that prose provides a sandbox.

The bundle is nested deliberately. It does not activate the root repository's
agents or change its policy. Integration must materialize the complete bundle,
resolve the local team root and pass the actual admission envelope. Native
Copilot `--agent squad --disable-builtin-mcps` reads committed references/skills
with file tools; no Squad CLI, SDK package or state MCP bridge is required.
See `.squad/native-gh-aw.md`. Merely copying the coordinator without its team
and constraints is not a supported CAO integration.
