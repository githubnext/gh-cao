# CAO modernization mission

Use real specialist capability to deliver this bounded lifecycle:

1. Evidence-based assessment of explicitly enrolled repositories.
2. One centrally coordinated proposal with shared contracts and dependencies.
3. Explicit human approval of that proposal and its per-repository issue scope.
4. Approved issues produced only through the central workflow's declared safe
   outputs, with immutable plan/source references and dependency criteria.
5. Dependency-gated Squad implementation inside a CAO-admitted, one-target
   worker; independently reviewed changes returned only as a **draft PR** through
   a declared safe output.
6. Cross-repository verification against approved contracts and actual revision-
   bound evidence; humans retain merge and operational decisions.

This bundle contains the actual 85 specialist and four support identities, not
89 independent workers or permission to fan out across a fleet. Squad coordinates
expertise within an already admitted task. CAO owns repository discovery,
enrollment, exact-workflow-SHA policy resolution, scope, mode and dispatch.
`review` remains the default; no team instruction enables live operation.

The deployment destination is the engagement's **explicitly reviewed
requirement**, never a default cloud, framework or migration decision. Azure is
one area of expertise, not a destination mandate. Retain/no-change, in-place
upgrades, coexistence, and existing desktop or mobile clients remain first-class
options. No automatic platform, database, UI, Aspire or Dapr conversion.

The team may assess, plan, implement and validate according to the particular
admitted task. Assessment does not execute source scripts. Plan approval does
not itself authorize implementation; approved issue scope, satisfied dependencies,
fresh evidence and CAO admission are also required. Implementation permission
does not authorize deployment, production migration, cutover, rollback,
decommissioning, Git publication or merge.

There is no automatic monitoring, issue claiming, git publication, workflow
dispatch, cross-Squad dispatch or merge. Scribe, Ralph, Rai and Fact Checker
remain real support identities with explicit bounded roles, not autonomous
automation. No histories, customer evidence or learned memories were imported.
